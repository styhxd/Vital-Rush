# VITAL RUSH

Shooter por dentro do corpo. Você é o Vital: o corpo claro segue o movimento, o miolo aceso é a vida.

A campanha passa por cinco órgãos — molar, fígado, coração, pulmão e cérebro — em trinta ondas. A ordem sai sorteada. São 120 caminhos, e cada um é uma doença. O prontuário apresenta o paciente. Quando o órgão muda, o jogo para e diz por que a infecção foi parar ali.

## Uma partida

O nome, a idade e o foco saem na hora. Esta foi a Iracema.

<img src="docs/prontuario.jpg" alt="Prontuário da Iracema Bittencourt, abscesso na polpa do molar" width="100%">

No molar a faixa avisa e as paredes fecham. O golpe é quando elas se encontram.

Entre um órgão e o outro, a partida para e explica a passagem.

O resto do corpo muda de cor e de problema. Coração, pulmão, cérebro.

O DNA que cai no chão paga o bio-laboratório. Mitose, membrana, anticorpo, e o que mais der. No começo da ficha a conta está zerada, e o cartão que você não pode comprar fica à vista.

<img src="docs/laboratorio.jpg" alt="Bio-laboratório com a biomassa ainda em zero" width="100%">

Bactéria, vírus, fungo, parasita. O chefe fica na última onda do órgão. Três vidas. O desvio deixa você intocável por um instante. O pulso empurra o que está perto e puxa a moeda.

Quatro dificuldades. O Normal de hoje é o Expert de antes. Fácil existe para aprender o caminho. O jogo fala português, inglês e espanhol.

No teclado, as setas ou WASD andam, Shift desvia, espaço solta o pulso. No celular o manche aparece sozinho, e a tela trava deitada.

## Rodar

Precisa de Node.js.

```
npm install
npm run dev
```

Abre em `http://localhost:5173`. `npm run build` gera a pasta `dist`. A casca de Android está em `android`, com Capacitor.
